# 🍌 Toscas

**Não sabe o que assistir? Deixa que o Toscas escolhe!**

Toscas é um aplicativo mobile de escolhas aleatórias desenvolvido como parte da atividade **“Eu Escolho Você!”**. A proposta é ajudar os usuários a resolver pequenas indecisões do cotidiano de maneira simples, divertida e visualmente agradável.

Nesta versão, o aplicativo é direcionado à escolha de filmes: o usuário pode visualizar uma coleção de opções e sortear um filme para decidir o que assistir.

## 🎯 Objetivo do projeto

Desenvolver uma aplicação mobile funcional, com interface intuitiva e uma identidade visual própria, capaz de realizar escolhas aleatórias dentro de um tema definido.

O projeto também tem como objetivo explorar conceitos de desenvolvimento mobile, construção de interfaces e navegação entre telas utilizando tecnologias do ecossistema Android.

## 📱 Interface e identidade visual

A identidade visual do Toscas foi pensada para transmitir personalidade, diversão e simplicidade.

A interface utiliza uma combinação de cores contrastantes, componentes com cantos arredondados e elementos visuais inspirados no universo do entretenimento.

### Telas e componentes

- **Filme sorteado:** apresenta o resultado da escolha aleatória em destaque.
- **Lista de filmes:** permite visualizar as opções disponíveis.
- **Navegação inferior:** facilita a alternância entre as funcionalidades.
- **Identidade visual:** logotipo e ícone desenvolvidos para representar a personalidade do aplicativo.

## 🛠️ Tecnologias utilizadas

- **Kotlin** — linguagem de programação.
- **Jetpack Compose** — construção declarativa das interfaces Android.
- **Material 3** — componentes e estrutura visual.
- **Navigation Compose** — gerenciamento da navegação entre telas.

## 🚀 Executando o projeto

1. Clone o repositório:

   ```bash
   git clone <URL_DO_REPOSITORIO>
   ```

2. Abra o projeto no **Android Studio**.

3. Aguarde a sincronização das dependências do Gradle.

4. Execute a aplicação em um emulador Android ou dispositivo físico compatível.
